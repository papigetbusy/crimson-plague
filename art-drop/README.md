# Art drop: pictures from Grok

Grok puts reference pictures here. Claude builds the 3D models in code from them (or wires in Grok's finished `.glb` files from `assets/models/`).

- `art-drop/gun/` : pictures of the gun (side, front, top, details like the red dot, mag, gold trim)
- `art-drop/monsters/` : pictures of each monster (front, side, back if possible)
- Name files clearly: `gun_side.png`, `demon_front.png`. A short `notes.txt` per folder for anything a picture can't say (colours, what glows, what moves).
- Plain PNG or JPG. These are references, not shipped to players.
- Never overwrite a picture the owner approved; add `_v2`.
